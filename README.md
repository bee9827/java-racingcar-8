# java-racingcar-precourse

# 입력 
- 경주할 자동차 이름 
    - 이름은 쉼표로 구분한다.  

```
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)  
pobi,woni,jun
```

- 몇 번의 이동을 할 것인지 입력한다.

```
시도할 횟수는 몇 회인가요?  
5
```

# 비즈니스
## 자동차 관리
- 이름을 관리한다.
    - 이름은 5자 이하만 가능하다. 5자를 넘을 경우 예외를 발생시킨다.
- 위치를 관리한다. 
    - 0~9 사이의 값을 받으며, 무작위 값이 4 이상일 경우 전진한다.

## 랜덤값 생성
- 무작위 값을 생성한다
    - 값의 범위는 0~9 이다.

## 게임 관리
- 자동차들을 관리한다.
- n대의 자동차는 주어진 횟수동안 전진하거나 멈춘다.
    - 랜덤값 생성기를 이용하여 0~9 사이의 값을 전달한다. 
- 우승자를 반환한다.
    - 우승자는 한 명 이상일 수 있다.
    - 우승자가 여러 명일 경우 쉼표`,`를 이용하여 구분한다.

# 출력
- 각 횟수마다 자동차들의 정보를 출력한다.

```
실행 결과
pobi : -
woni : 
jun : -

pobi : --
woni : -
jun : --

pobi : ---
woni : --
jun : ---

pobi : ----
woni : ---
jun : ----

pobi : -----
woni : ----
jun : ------

```
- 우승자의 정보를 출력한다.

```
최종 우승자 : pobi, jun
```

    
사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.
